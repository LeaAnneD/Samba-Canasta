# 🎮 Quick Start - See the Game on Your Phone!

Since you have **Expo Go** installed, you can see the game in just a few steps!

## Step 1: Install Dependencies (One Time)

Open your terminal in this folder and run:

```bash
npm install
```

This will download all the code packages needed. It might take 2-3 minutes.

## Step 2: Start the App

Once installation is done, run:

```bash
npm start
```

You'll see a **QR code** appear in your terminal!

## Step 3: Scan QR Code with Your Phone

### On iPhone:
1. Open your **Camera app**
2. Point it at the QR code on your computer screen
3. Tap the notification that pops up
4. Expo Go will open and load the game!

### On Android:
1. Open the **Expo Go** app
2. Tap "Scan QR Code"
3. Point your phone at the QR code on your screen
4. The game will load!

## What You'll See

The game will open on your phone and you'll see:
- A green game board background
- Player 1's cards at the bottom
- Stock pile and discard pile info
- Buttons to draw cards and end turn

## How to Test It

1. **Draw 3 Cards** - Tap the "Draw 3 Cards" button
2. **Discard a Card** - Tap any card in your hand to discard it
3. **End Turn** - Tap "End Turn" to go to next player
4. **View Game Log** - Scroll down to see what's happening

## Troubleshooting

**If the QR code doesn't appear:**
- Make sure you ran `npm install` first
- Try closing the terminal and running `npm start` again

**If Expo Go says "Can't connect":**
- Make sure your phone and computer are on the same WiFi network
- Try pressing `r` in the terminal to reload
